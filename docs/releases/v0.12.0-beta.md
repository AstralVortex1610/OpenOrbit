**Orbit is in beta.** Expect rough edges, and please open an issue when something breaks.

**Install:** download `Orbit-0.12.0-win.zip`, unzip it, and run `Orbit.exe`.

## What's new
- **Orbiter (beta):** Orbit's coding agent. Sessions per folder, file edits with diffs, checkpoints and rewind, `/compact`, `/init`, ORBITER.md memory (also reads AGENTS.md and CLAUDE.md), 16 slash commands and 5 permission modes.
- **Spark, Pulse and Surge:** Orbit's own model line, mapped to any model you like.
- **Per-project models**, plus a chat → Orbiter handoff and an Orbiter status tool for chat.
- **Scene themes for Orbiter:** Orbit Nebula, Paris at Night, Mount Fuji, Racing Red, Snowfall and Retro 95, plus custom JSON themes that can use your own picture.

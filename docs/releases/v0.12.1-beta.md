**Orbit is in beta.** Expect rough edges, and please open an issue when something breaks.

**Install:** download `Orbit-0.12.1-win.zip`, unzip it, and run `Orbit.exe`. Already on Orbit? It updates itself (see below), or go to Settings → Updates → Install.

## What's new
- **Orbiter lives inside Orbit.** No more separate window. Click **Orbiter** in the left rail and it opens in the main window.
- **Orbiter inside projects.** Every project has a **Chat | Orbiter** switch at the top. Orbiter sessions there use the project's folder and model, and only that project's sessions show up.
- **One model picker everywhere.** Chat, each project and each Orbiter session have a model button showing exactly which model is running (for example `Surge · kimi-k3.1-pro`).
- **Switching the model mid-task now works.** Pick a different model while a task is running and the current step restarts on the new model straight away. The task keeps its progress.
- **Simpler Brain settings.** Spark, Pulse and Surge are now three model names on the same provider and key as your main model. No extra base URLs or keys. Leave one empty and it uses the main model.
- **Chat → Orbiter handoff keeps your model.** Work handed from chat or a project opens in Orbiter with the same model you picked there. Handoffs from a project open in that project's Orbiter tab.

## Fixes
- **Updates install by themselves.** Before, Orbit only *checked* for updates. Now it checks every hour, downloads in the background and installs when Orbit is idle and you're not using it. It also installs when you quit. You can still click Install now.
- **"fetch failed" errors explain themselves.** You now see which provider and model failed and why (wrong base URL, no internet, timeout, certificate). Orbit also retries a dropped connection once before switching to a backup.
- **Picked model ignored.** A model that errored earlier could be skipped for 10 minutes, so Orbit kept answering on the old one. Choosing a model now clears that, and your choice is used.
- **Wrong key on a tier.** A tier left with an old key from another provider could send that key to your main provider. Tiers now always use the Brain's key unless they have their own base URL.
- Orbiter's default model for new sessions is now your main model instead of Pulse, so an unset Pulse no longer runs a model you didn't expect.
- Orbiter's side panel (Tasks / Changes / Checkpoints) can be hidden with the button at the top right. It hides automatically on narrow windows.

**Orbit is in beta.** Expect rough edges, and please open an issue when something breaks.

**Install:** Orbit updates itself. Or download `Orbit-0.12.2-win.zip`, unzip it, and run `Orbit.exe`.

## Fixes
- **Main chat always uses your main model.** The model button is gone from the main chat. Chat runs on the model you set in Settings → Brain, and switching it there moves a running task over to the new model straight away.
- Handoffs from main chat to Orbiter now use the main model too.

## Unchanged
- Projects and Orbiter sessions still have their model button, so each project can keep its own model.

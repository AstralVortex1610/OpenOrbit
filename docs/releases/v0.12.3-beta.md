**Orbit is in beta.** Expect rough edges, and please open an issue when something breaks.

**Install:** Orbit updates itself. Or download `Orbit-0.12.3-win.zip`, unzip it, and run `Orbit.exe`.

## What's new
- **Quick thinking (on by default in chat).** Thinking models (DeepSeek, Gemini, Kimi…) are asked to think briefly, so the first word comes much sooner. Change it in Settings → Brain → *Thinking in chat* / *Thinking in Orbiter* (Quick, Model default, Deep). If your provider doesn't support it, Orbit notices and stops sending it.
- **Speed log.** `perf.log` in Orbit's data folder records every model step: total time, time to first word, input tokens and how many came from the provider's cache.

## Fixes (speed)
- **Every step used to re-send a "new" request.** The clock in Orbit's instructions changed every second, and old tool output was trimmed differently on each step, so providers could never reuse their cache and re-read the whole conversation each time. Now a task's instructions and history stay identical from step to step, and history is only trimmed occasionally, in big chunks. Steps after the first are much faster, and cost less, on providers that cache (DeepSeek, OpenAI, Gemini, Kimi and most others).
- **Orbiter's todo list no longer changes the instructions** on every update. The list now comes back in the todo tool's result.
- **More work runs side by side.** Read-only calls (read, glob, grep, search, fetch) in the same step run at once even when an edit or command is in that step too. Before, a single edit made the whole step run one call at a time.
- **Fewer steps.** Orbit and Orbiter are told to batch lookups into one step, never repeat a call, keep tool output small, and run full test suites once at the end instead of after every edit.

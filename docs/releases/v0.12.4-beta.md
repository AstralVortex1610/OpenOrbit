**Orbit is in beta.** Expect rough edges, and please open an issue when something breaks.

## What's new
- **Edit your messages.** Hover any message you sent and press Edit. Orbit redoes its answer from that point. In Orbiter, editing also undoes the code changes made after that message.
- **Reports in the chat, not PDFs.** Updates, summaries and research now show as a card in the chat that you can expand and collapse. Orbit only makes a PDF, Word or slides file when you ask for one.
- **Orbiter shows it's working.** A live row at the bottom says what Orbiter is doing right now ("Read src/app.js", "Thinking", "Waiting for you") with a running timer. The screen is never blank while it works.
- **"Orbiter is asking you" banner.** When Orbiter has a question and you're somewhere else in Orbit, a banner tells you, with an Answer button that takes you there.
- New setting **Settings → Brain → Hand work to Orbiter**: "Only when I ask for Orbiter" (the default) or "May suggest it, waits for my yes".

## Fixes
- **HTTP 413 "request body is larger than 8388608 bytes".** Big pictures are now resized (max 1600 px, JPEG) before they're sent. Every request is kept under 7 MB by dropping older images first and then trimming the longest old outputs. If a provider still says it's too big, Orbit retries once without images instead of failing.
- Chat no longer hands work to Orbiter on its own. It only does so when you ask for Orbiter by name, and the handoff is blocked in code, not just in the prompt. "Don't use Orbiter" holds for the rest of the conversation.
- The quick-reply lane (the answer you get while Orbit is busy) can no longer hand work off. Instructions you give it, like "don't…" or "instead…", are always passed to the running task. It no longer makes promises the running task doesn't keep.
- Orbiter questions no longer get lost. A question stays on screen after you switch sessions or views, until you answer it.
- When Orbiter or Orbit says "let me ask you…" or "now I'll…" and then stops, it is sent back to actually ask or do it.
- When a reply claims "fixed" or "done" but nothing was changed in that turn, it is sent back to make the change or say plainly that nothing changed. The false reply is taken off screen.
- In projects, Orbit asks 1 to 3 short questions (with a "Decide yourself" option) before building anything from a vague request, and says which files it will rewrite before rewriting them.
- Orbiter now uses Quick thinking by default (it was Model default, which was slow). You can change it in Settings → Brain.

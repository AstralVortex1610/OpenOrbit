**Orbit is in beta.** Expect rough edges, and please open an issue when something breaks.

## What's new
- **Sandbox (beta): Orbit's own computer.** Turn it on in Settings → Sandbox and press Set up. Orbit installs its own Linux (WSL2) with Node 22, Python 3, git and a browser already in it.
  - Commands and installs happen there, not on your Windows.
  - Browsing happens there with no window, so nothing pops up while you work.
- **Computer panel.** The Computer button at the top shows a live view of Orbit's browser and its terminal.
- **Shared folders.** The sandbox sees none of your PC until you share a folder or drive. Each one is set to:
  - **Read only:** it can look.
  - **Ask first:** it works on a copy and you approve changes.
  - **Full access:** it edits your real files, and changes show up on Windows instantly.
  - Orbit asks before using a pen drive you just plugged in.
- **Windows-only jobs** like Excel, Blender, CAD or your screen still work. They run on Windows after you say OK. Blender can run hidden in the background.
- **Keeps itself small.** Each task's scratch files are deleted when it ends. A daily clean-up clears caches and old temp files, and freed space goes back to Windows. Your shared files are never deleted unless you ask.

## Fixes
- **Automatic updates actually happen now.**
  - Checks use Windows' own network settings (proxy and certificates), which fixes the silent "fetch failed".
  - A failed check retries in 2, 5, 15 and 30 minutes instead of waiting an hour, and checks again after the laptop wakes from sleep.
  - The update installs as soon as Orbit is hidden, minimised or in the background, not only after 5 idle minutes.
  - Every step is written to update.log.
